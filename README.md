# Винхайлин — чат-бот для бесед ВКонтакте

Бот для сообщества ВК, которого добавляют в беседы, чтобы он в них общался.
Мозги — AI-агент Timeweb Cloud (модель GPT-5.4), общение с ВК — через Bots Long Poll API
(не нужен домен, белый IP и вебхуки). Разворачивается одной командой через Docker Compose.

## Что умеет

- Общается в беседах: отвечает на упоминания `@сообщество`, на ответы (reply) на свои
  сообщения и на обращения по имени («Винхайлин», «Виня» — настраивается).
- Иногда сам влезает в разговор (вероятность настраивается, по умолчанию 5%).
- Помнит последние сообщения беседы (по умолчанию 30) и понимает, кто что писал.
- Всегда отвечает в личных сообщениях сообщества.
- Здоровается, когда его добавляют в беседу.
- Характер задаётся системным промптом в `.env`.

## Шаг 1. Настройка сообщества ВКонтакте

1. **Управление → Настройки → Работа с API → Ключи доступа** → «Создать ключ»,
   отметьте право **«сообщения сообщества»**. Скопируйте токен — это `VK_GROUP_TOKEN`.
2. **Работа с API → Long Poll API**: включите, версия API — **5.199**.
   На вкладке «Типы событий» отметьте **«Входящее сообщение»**.
3. **Управление → Сообщения**: включите сообщения сообщества.
   В **Настройки для бота** включите «Возможности ботов» и
   **«Разрешать добавлять сообщество в беседы»**.
4. Добавьте бота в беседу: в беседе «Добавить участника» → выберите сообщество.
   ⚠️ Чтобы бот видел **все** сообщения (а не только упоминания), в настройках беседы
   дайте ему **доступ ко всей переписке** (сделайте администратором беседы).

## Шаг 2. Создание AI-агента в Timeweb Cloud

1. В [панели Timeweb Cloud](https://timeweb.cloud/) откройте раздел **AI-агенты** и создайте агента.
2. Выберите модель **GPT-5.4**. Системный промпт в панели можно оставить пустым —
   бот отправляет свой промпт из `.env` (характер персонажа).
3. На вкладке **«Дашборд»** агента возьмите **ID агента** (`TIMEWEB_AGENT_ID`)
   и создайте **API-ключ** (`TIMEWEB_AGENT_TOKEN`).

Бот использует [OpenAI-совместимый API агента](https://timeweb.cloud/docs/ai-agents/api-usage/openai-compatible-api):
`https://agent.timeweb.cloud/api/v1/cloud-ai/agents/{agent_id}/v1/chat/completions`.
Модель в запросе игнорируется — используется та, что выбрана в настройках агента.

## Шаг 3. Деплой

Есть два способа — выберите один.

### Вариант А: Timeweb Apps (авто-деплой из Git по `docker-compose.yml`)

`.env`-файла в репозитории **нет и не должно быть** (он в `.gitignore`, там секреты) —
платформа Timeweb Apps сама подставляет переменные окружения из своего интерфейса.

1. В панели Timeweb Cloud создайте приложение → **App Platform** → тип **Docker Compose**,
   укажите репозиторий `poilk777/vinhailyn_bot` и ветку.
2. На шаге настройки переменных окружения добавьте те же ключи, что в `.env.example`
   (`VK_GROUP_TOKEN`, `VK_GROUP_ID`, `TIMEWEB_AGENT_ID`, `TIMEWEB_AGENT_TOKEN`, при
   желании остальные — иначе возьмутся значения по умолчанию из `docker-compose.yml`).
3. Запустите деплой. Если платформа пишет `env file ... not found` — это нормально,
   это просто означает отсутствие `.env`-файла в репозитории; сам деплой не ломается,
   при условии что обязательные переменные (`VK_GROUP_TOKEN`, `TIMEWEB_AGENT_ID`,
   `TIMEWEB_AGENT_TOKEN`) заданы через интерфейс.

### Вариант Б: облачный сервер по SSH

1. Создайте в Timeweb Cloud облачный сервер (подойдёт самый дешёвый тариф,
   1 CPU / 1 ГБ RAM) с образом **Docker** (или Ubuntu + установите Docker вручную).
2. Подключитесь по SSH и выполните:

```bash
git clone https://github.com/poilk777/vinhailyn_bot.git
cd vinhailyn_bot
cp .env.example .env
nano .env        # заполните токены
docker compose up -d --build
```

3. Проверка и управление:

```bash
docker compose logs -f      # смотреть логи
docker compose restart      # перезапустить
docker compose down         # остановить
```

После изменения `.env` перезапустите: `docker compose up -d`.
После обновления кода: `git pull && docker compose up -d --build`.

## Настройки (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `VK_GROUP_TOKEN` | Токен сообщества ВК | — (обязательно) |
| `VK_GROUP_ID` | ID сообщества | определяется автоматически |
| `TIMEWEB_AGENT_ID` | ID AI-агента Timeweb | — (обязательно) |
| `TIMEWEB_AGENT_TOKEN` | API-ключ агента | — (обязательно) |
| `AI_MODEL` | Модель (для совместимости) | `gpt-5.4` |
| `AI_TEMPERATURE` | Температура генерации | `1.0` |
| `AI_MAX_TOKENS` | Максимум токенов в ответе | `600` |
| `SYSTEM_PROMPT` | Характер бота | встроенный «Винхайлин» |
| `BOT_NAMES` | Имена для отклика, через запятую | `винхайлин,виня,vinhailyn` |
| `RANDOM_REPLY_CHANCE` | Шанс влезть в разговор самому (0..1) | `0.05` |
| `HISTORY_SIZE` | Сколько сообщений беседы помнить | `30` |

```
Dockerfile
docker-compose.yml
.env.example — шаблон настроек
```
